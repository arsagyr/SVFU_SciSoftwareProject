# Лабораторная работа №4 
Организация научного программного проекта на Python

## Задание 
Преобразовать исходный скрипт в научный проект, добавить новые
численные характеристики и выполнить индивидуальный вариант.
Итоговые файлы в каталоге results/:
    - data.csv с колонками x и y
    - metrics.txt с семью численными характеристиками
    - plot.png с графиком функции

### Схема проекта 
```
scientific_project/
├── app.py                ← Flask-приложение
├── main.py               ← ваш существующий CLI-скрипт
├── src/
│   ├── calculations.py
│   └── visualization.py
├── templates/
│   └── index.html
└── results/              ← сюда сохраняются plot.png, data.csv, metrics.txt
```

### Состав отчёта 
1. титульная часть: номер и тема лабораторной работы
2. цель работы
3. снимок структуры каталогов
4. полный код main.py и файлов из src/
5. команды создания окружения, установки и запуска
6. содержимое metrics.txt и полученный график
7. краткий вывод: зачем код разделён на модули
