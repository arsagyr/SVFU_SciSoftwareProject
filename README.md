# Лабораторная работа №5 - NumPy: эффективные научные вычисления и векторизация

NumPy в научных вычислениях
- хранит однородные числовые данные в компактном массиве
ndarray
- выполняет операции сразу над всем массивом или его частью
- поддерживает многомерные данные, маски и агрегирование
- служит основой для SciPy, pandas, Matplotlib и многих численных библиотек

На этой работе: одно и то же двумерное поле вычисляется циклами Python и векторизованными выражениями NumPy.
## Список Python и массив NumPy
Список
- может хранить объекты разных типов
- арифметика обычно требует цикла
- умножение списка повторяет элементы

ndarray

- хранит элементы одного типа
- арифметика выполняется поэлементно
- форма массива задаёт структуру данных

NumPy особенно полезен для больших серий одинаковых численных операций. На малых массивах накладные расходы могут быть сопоставимы с самим вычислением.

Создание массивов
```
import numpy as np
a = np.array([1.0, 2.0, 3.0])
x = np.arange(0.0, 1.0, 0.2)
y = np.linspace(−1.0, 1.0, 5)
z = np.zeros((3, 4))
```
array создаёт массив из готовой последовательности arange использует шаг; для вещественных границ конец может не совпасть с ожидаемым
linspace создаёт заданное число равномерных значений, включая границы
zeros создаёт массив указанной формы, заполненный нулями

Форма и размерность
```
A = np.zeros((3, 4))
A.shape # (3, 4)
A.ndim # 2
A.size # 12
```
- shape хранит длину массива по каждой оси
- ndim показывает число осей
- size показывает общее число элементов
Для поля U формы (ny, nx) первая ось соответствует строкам, то
есть координате y, а вторая ось соответствует столбцам и
координате x.

## Поэлементные операции

```
x = np.linspace(0.0, 2.0, 5)
u = np.sin(x) + 0.5 ∗ x∗∗2
v = np.exp(−x) ∗ u
```

- +, -, *, / и ** применяются к каждому элементу
- np.sin, np.exp, np.sqrt принимают массивы
- оператор * означает поэлементное умножение
- матричное умножение записывается отдельно: A @ B

## Векторизация вместо цикла
Цикл Python
```
result = []
for value in x:
result.append(
np.sin(value) + value∗∗2
)
```
 Выражение NumPy
```
result = np.sin(x) + x∗∗2
```
Векторизованная запись короче и передаёт повторяющиеся операции
внутренним циклам NumPy. Она часто быстрее на больших массивах,
но преимущество зависит от размера данных и вида операции.
 
Broadcasting
```
x = np.array([1.0, 2.0, 3.0]) # shape (3,)
y = np.array([[10.0], [20.0]]) # shape (2, 1)
field = x + y # shape (2, 3)
[1 2 3] + [10]  = [11 12 13]
          [20]    [21 22 23]

```
При сравнении форм справа налево размеры должны совпадать или
один из них должен равняться 1.

x = np.linspace(−2.0, 2.0, 5)[None, :] # (1, nx)
y = np.linspace(−1.0, 1.0, 3)[:, None] # (ny, 1)
U = np.exp(−(x∗∗2 + y∗∗2)) # (ny, nx)
- None добавляет ось длины 1
- x распространяется по строкам
- y распространяется по столбцам
- полный массив пар координат заранее создавать не требуется
