# Лабораторная работа №7 - Разреженные матрицы и решение СЛАУ в SciPy
## О матрицах и люд... о методах их хранения
|Формат| Что хранится| Практический смысл|
|-----|---------------------------|------------------------|
| COO | значения, строки, столбцы |удобно собирать элементы по координатам|
| CSR | data, indices, indptr | быстрый доступ по строкам и матрично-векторное умножение |
| CSC | данные с группировкой по столбцам | удобен для операций, ориентированных на столбцы |

## Часть A. Построение матриц
1. выбрать вариант, N, параметр α и функцию f
2. создать xi = i/(N + 1) и bi = f(xi)
3. для малого N построить плотную матрицу NumPy
4. построить sparse array и получить формат CSR
5. проверить shape, nnz, dtype
6. сравнить элементы двух матриц только на малом размере
Ожидается nnz = 3N − 2.

## Часть B. Решение и проверка
1. решить малую плотную систему через numpy.linalg.solve
2. решить CSR-систему через scipy.sparse.linalg.spsolve
3. сравнить решения с абсолютным и относительным допусками
4. вычислить абсолютные и относительные невязки
5. оформить краткую таблицу сравнения
Таблица должна различать метод, тип матрицы, невязку, время
построения, время решения и память.

## Часть C. Исследование памяти
Для каждого выбранного N оценить:
Mdense = 8N2, MCSR = Mdata + Mindices + Mindptr.
- плотную матрицу реально создавать только при небольшом N
- для большого N вычислять теоретический объём плотного
хранения
- построить один график зависимости памяти от N
- подписать единицы измерения и оси

## Часть D. Вычислительный эксперимент
Рекомендуемые размеры: N = 80, 160, 320, 1000, 5000, 20000.
- плотный расчёт проводить только до безопасного предела,
например N ≤ 320
- отдельно измерять построение матрицы и решение системы
- выполнить несколько повторов и сохранить медиану
- не включать печать, графики и запись файлов в измеряемый
участок
- для каждого размера вычислить относительную невязку
Размеры можно уменьшить, если полный запуск на учебном
компьютере занимает слишком долго.

### Модуль matrices.py
Реализовать функции со следующими контрактами:
- def build_rhs(n, f): """Вернуть x иодномерныйвекторb длины n."""
- def build_dense_matrix(n, alpha): """Вернуть ndarray формы(n, n)."""
- def build_sparse_matrix(n, alpha): """Вернуть CSR sparse array формы(n, n)."""

Проверить N ≥ 2, α > 0, форму и конечность правой части. Сравнение через toarray() вынести в отдельную проверку для малого N.

### Модуль analysis.py
Предусмотреть компактный набор функций:
- def residual_metrics(matrix, solution, rhs): ...
- def solve_dense(matrix, rhs): ...
- def solve_sparse(matrix, rhs): ...
- def dense_memory_bytes(n): ...
- def csr_memory_bytes(matrix): ...
- def benchmark_variant(alpha, f, sizes, ...): ...

Возвращать данные, а не печатать их внутри вычислительных функций. Это позволяет отдельно сохранить таблицу и построить график.

### main.py и результаты

1. получить данные своего варианта из таблицы
2. выполнить малое плотное/разреженное сравнение
3. запустить безопасную серию размеров
4. сохранить results/experiment.csv или JSON
5. сохранить results/memory.png
6. вывести краткую сводку: N, nnz, невязки, память
Основной алгоритм не должен переписываться при смене
варианта.
