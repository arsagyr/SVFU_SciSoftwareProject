# Лабораторная работа  SciPy: численное решение прикладных задач
SciPy в научном Python
- NumPy хранит массивы и выполняет базовые операции над ними
- SciPy предоставляет готовые численные алгоритмы поверх NumPy
- библиотечный метод нужно выбирать по условиям задачи и проверять после вычисления
- результат включает не только число, но и признаки сходимости или оценку ошибки

Рабочая схема: собственный базовый метод, алгоритм SciPy, независимая проверка и сохранённое сравнение.

Основные модули SciPy
- optimize корни уравнений, минимизация и подбор параметров
- integrate численное интегрирование и задачи с дифференциальными уравнениями
- linalg расширенные алгоритмы линейной алгебры sparse хранение и обработка разреженных матриц
- interpolate построение приближённых функций по дискретным данным
В этой работе используются только optimize и integrate. 

Корень нелинейного уравнения
Искомое число x∗ удовлетворяет условию
f(x∗) = 0.
Для непрерывной функции условие
f(a)f(b) < 0
гарантирует наличие хотя бы одного корня внутри [a, b].
- смена знака не гарантирует единственность корня
- отсутствие смены знака не доказывает отсутствие корня
- выбранный интервал должен лежать в области определения
функции

## Бисекция и метод Брента
Бисекция
- делит интервал пополам
- сохраняет интервал со
сменой знака
- проста для самостоятельной
реализации
- имеет предсказуемое, но
линейное сужение интервала
Brentq
- также использует
заключающий интервал
- сочетает надёжные и
ускоряющие шаги
- обычно требует меньше
вычислений функции
- применяется как готовый
алгоритм SciPy
## Проверка найденного корня
После завершения метода проверяют несколько характеристик:
- сходимость: алгоритм завершился штатно
- принадлежность интервалу: x∗ ∈ [a, b]
- невязка: r = |f(x∗)|
- согласованность: корни двух методов близки с учётом допусков
Число знаков после запятой само по себе не является проверкой.
Следует выводить допуски, невязку и состояние метода.

##  Невязка и ошибка корня
Рассмотрим f(x) = ε(x − 1), где ε = 10−8.
x = 2, |f(2)| = 10−8, |2 − 1| = 1.
Невязка мала, но приближение корня ошибается на единицу.
- невязка измеряет точность выполнения уравнения
- ошибка корня измеряет расстояние до истинного решения
- при малом наклоне функции одна характеристика может быть
малой, а другая большой
Вывод: невязку нужно оценивать вместе с интервалом, допуском и
поведением функции.

## Численное интегрирование
Требуется приблизить значение
Увеличение n обычно улучшает результат для гладкой функции, но
само по себе не доказывает точность.

Интегрирование через quad
```
from scipy.integrate import quad
value, error_estimate = quad(
  g,
  a,
  b,
  epsabs=1e−10,
  epsrel=1e−10,
)
```
- value — вычисленное приближение интеграла
- error_estimate — оценка абсолютной численной ошибки алгоритма
- оценка не равна фактической ошибке относительно точного значения
- результат quad нельзя объявлять абсолютно точным

## Три разных величины при сравнении
- Разность методов |Tn − Iquad| показывает согласование двух
вычислений
- Оценка quad внутренний индикатор алгоритма, возвращаемый SciPy
- Фактическая ошибка |Inum − Iexact|, если точное значение известно
- Относительная ошибка
|Inum −Iref|/|Iref|, если знаменатель не близок
к нулю
Эти величины отвечают на разные вопросы и не должны называться
одним словом «погрешность» без уточнения.

Согласованные допуски и проверки
- задавайте одинаковые xtol, rtol и max_iter для сравнимых
запусков
- в собственной бисекции останавливайтесь по ширине
заключающего интервала
- сравнивайте корни через комбинированный абсолютный и
относительный допуск
- для интеграла исследуйте последовательность T50, T100, T200, T400
- сохраняйте исходные параметры вместе с численными ответами
Совпадение двух методов повышает доверие к результату, но не
заменяет проверку условий применимости.
