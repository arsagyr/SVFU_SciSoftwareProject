# Лабораторная работа №4 
Организация научного программного проекта на Python

## Задание 
Преобразовать исходный скрипт в научный проект, добавить новые
численные характеристики и выполнить индивидуальный вариант.
Итоговые файлы в каталоге results/:
    - data.csv с колонками x и y
    - metrics.txt с семью численными характеристиками
    - plot.png с графиком функции

### Схема проекта 
```
scientific_project/
├── app.py                ← Flask-приложение
├── main.py               ← CLI-скрипт
├── src/
│   ├── classes.py        ← Модуль классов
│   ├── calculations.py   ← Модуль вычислений
│   └── visualization.py  ← Модуль представления графиков
├── templates/
│   └── index.html        ← Шаблон web-страницы
└── results/              ← папка результатов
```

## Установка
### Порядок действий
1. Создать виртуальное окружение
2. Активировать окружение
3. Установить зависимости
4. Запустить проект
### Мануал
```
python3 -m venv venv  # Создать виртуальное окружение
source venv/bin/activate  #  Активировать окружение
make install  # Установить зависимости
make web  # Запустить проект
```
